# 📊 Dashboard Preview

## Overview

The **Bank Loan Analysis Dashboard** is an interactive Power BI report designed to provide insights into loan applications, funding, repayments, portfolio quality, and borrower demographics. The report is divided into three dashboard pages, each serving a unique analytical purpose.

---

# 📈 1. Summary Dashboard

The **Summary Dashboard** provides an executive overview of the bank's lending performance through key performance indicators (KPIs).

### Key Highlights

- Total Loan Applications
- Total Funded Amount
- Total Amount Received
- Average Interest Rate
- Average Debt-to-Income Ratio (DTI)
- Good Loan Percentage
- Bad Loan Percentage
- Month-to-Date (MTD) Metrics
- Previous Month-to-Date (PMTD) Comparison

# 📊 2. Overview Dashboard

The **Overview Dashboard** helps analyze lending trends across different business dimensions using interactive charts and visualizations.

### Visualizations Included

- Monthly Loan Trends
- State-wise Loan Distribution
- Loan Term Analysis
- Employment Length Analysis
- Loan Purpose Analysis
- Home Ownership Analysis

# 📋 3. Details Dashboard

The **Details Dashboard** provides a detailed, transaction-level view of all loan records, enabling users to drill down into individual loans.

### Information Available

- Loan ID
- Loan Amount
- Funded Amount
- Total Amount Received
- Interest Rate
- Debt-to-Income Ratio (DTI)
- Loan Status
- Grade & Sub-grade
- Employment Length
- Home Ownership
- Loan Purpose
- State
- Issue Date
