# 📊 Bank Loan Analysis Dashboard | Power BI

A comprehensive **Bank Loan Analysis Dashboard** built using **Power BI** and **SQL** to analyze loan applications, borrower behavior, portfolio performance, and loan quality. This project provides business insights that help financial institutions monitor lending performance, identify risks, and support data-driven decision-making.

---

## 📌 Project Overview

Banks process thousands of loan applications every month. This dashboard transforms raw loan data into actionable insights by tracking key lending metrics, loan performance, repayment behavior, and customer trends.

The project includes:

- Interactive Power BI Dashboard
- SQL Queries for KPI generation
- Domain Knowledge Documentation
- Banking Terminologies
- Data Analysis and Visualization

---

## 🎯 Business Objectives

- Monitor overall lending performance
- Analyze loan approval trends
- Identify Good Loans vs Bad Loans
- Track repayment performance
- Understand customer demographics
- Support strategic lending decisions
- Improve portfolio monitoring

# 📈 Dashboard Pages

## 1. Executive Summary

Displays high-level KPIs including:

- Total Loan Applications
- Total Funded Amount
- Total Amount Received
- Average Interest Rate
- Average Debt-to-Income Ratio (DTI)
- Month-to-Date (MTD) Performance
- Previous Month-to-Date (PMTD) Comparison

---

## 2. Loan Quality Analysis

Tracks:

- Good Loan Percentage
- Bad Loan Percentage
- Good Loan Applications
- Bad Loan Applications
- Good Loan Funded Amount
- Bad Loan Funded Amount
- Loan Status Breakdown

## 3. Loan Portfolio Overview

Provides analysis across:

- Monthly Loan Trends
- State-wise Distribution
- Loan Term Analysis
- Employee Length
- Home Ownership
- Loan Purpose
